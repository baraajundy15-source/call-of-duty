# زِرّها — ZERHA 🔴

نسخة أولى من تطبيق ترفيهي يعمل بدون إنترنت.

## المزايا
- زر ضخم «اضغطني»
- عداد ضغطات
- نتائج عشوائية
- تأثير ضغط
- واجهة داكنة
- لا يحتاج إنترنت
- لا يحتاج تسجيل دخول
- لا يحتوي إعلانات في النسخة الأولى

## البناء
1. افتح المجلد في Android Studio.
2. انتظر Gradle Sync.
3. اختر Build > Build APK(s) لتجربة APK.
4. للنشر على Google Play استخدم Build > Generate Signed Bundle / APK واختر Android App Bundle (AAB).
5. أنشئ مفتاح توقيع خاصًا بك واحتفظ به بأمان.

ملاحظة: هذه النسخة تحفظ العداد أثناء تشغيل التطبيق فقط. يمكن في النسخة التالية إضافة حفظ دائم للعداد باستخدام DataStore.

# زِرّها — ZERHA v3.0

مشروع Android كامل مبدئي جاهز للفتح في Android Studio.

## المزايا
- زر تفاعلي مع عداد ضغطات
- أفضل رقم محفوظ
- رسائل عشوائية
- تأثير ضغط
- واجهة داكنة فخمة
- إعدادات: الوضع الداكن، الصوت، الاهتزاز
- تصفير العداد وأفضل رقم
- حفظ دائم عبر DataStore
- وضع عمودي
- يعمل بدون إنترنت بعد توفر تبعيات Gradle محليًا

## البناء
افتح المجلد في Android Studio، انتظر مزامنة Gradle، ثم:
Build > Generate Signed Bundle / APK > Android App Bundle

ملاحظة: توقيع AAB يتطلب keystore خاصًا بك؛ لا ينبغي تضمين مفتاح التوقيع داخل المشروع.

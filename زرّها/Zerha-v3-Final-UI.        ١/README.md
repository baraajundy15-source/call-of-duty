# زِرّها — ZERHA v3 🔴

أضيف في هذا الإصدار:
- حفظ دائم لعدد الضغطات عبر DataStore.
- أفضل رقم محفوظ حتى بعد إغلاق التطبيق.
- صفحة إعدادات.
- تشغيل/إيقاف صوت الضغط.
- تشغيل/إيقاف الاهتزاز.
- تصفير العداد وأفضل رقم.
- تأثير ضغط للزر.
- أيقونة أولية مخصصة للتطبيق.
- لا يحتاج إنترنت.

## البناء
افتح المجلد في Android Studio وانتظر Gradle Sync.
لإنشاء APK للتجربة: Build > Build APK(s).
للنشر: Build > Generate Signed Bundle / APK ثم اختر Android App Bundle.
